# SCOPE.md - Gravity4096 Scope Definition

## In-Scope Features
- **Galactic Core Attractor**: Central point gravity with smooth softened kernel and tangential swirl
- **N-Body Mutual Gravity**: Subtle mutual pull between celestial orbs for planetary cluster formation
- **Orbital Trajectory Preview**: Real-time multi-step path projection taking into account center gravity and wall rebounds
- **Bottom Launcher**: Aimable cannon at bottom center with interactive swipe/drag touch controls
- **Tier Progression**: 2 to 4096 celestial bodies with distinct colors, radii, textures, and masses
- **Merge Kinetics**: Elastic collision solver with smooth merge collapse animation and stardust shockwaves
- **Score & High Score**: Reactive score tracking with persistent local best score
- **Perimeter Danger Ring**: Outer boundary danger indicator with countdown timer if bodies linger outside safe orbit
- **Sound & Haptics**: Procedural Web Audio API sound effects and navigator.vibrate haptics
- **1-Click Backup & Restore**: JSON import/export for score and game state
