# Gravity4096

A celestial orbital 2048/4096 number-merge physics puzzle built with Vanilla JavaScript and HTML5 Canvas.

## Features
- **Orbital Gravity Mechanics**: Central galactic attractor with soft N-body mutual attraction and galaxy swirl
- **Bottom-Mounted Launcher**: Drag-to-aim and release-to-shoot with real-time orbital trajectory simulation
- **Tactile Merging**: Celestial bodies merge upon contact (2 to 4096+), generating shockwaves and stardust
- **Zero Third-Party Runtime Dependencies**: Pure ES2022 modules and Vanilla CSS
- **Strict Architecture**: Under 200 lines per file modular architecture

## Quick Start
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
